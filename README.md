# FaceVet: Система валидации и анализа изображений лиц

## Описание проекта
FaceVet - это автоматизированный пайплайн для проверки качества изображений лиц и извлечения биометрических характеристик с акцентом на точное определение возраста. Система последовательно анализирует фотографии через 6 этапов валидации и предоставляет детализированные отчеты.

## Ключевые особенности
- **Многоступенчатая валидация**: проверка формата, качества, положения лица и технических характеристик
- **Комплексный анализ**: возраст, пол, раса, эмоции и метаданные
- **Гибкая настройка**: параметры валидации можно адаптировать под конкретные задачи
- **Подробная отчетность**: CSV-файлы с результатами и визуализации

## Технологический стек
| Компонент | Назначение |
|-----------|------------|
| Python | Основной язык разработки |
| OpenCV | Обработка изображений |
| DeepFace | Анализ биометрических характеристик |
| RetinaFace | Детекция лиц |
| Pandas | Обработка и анализ данных |
| Scikit-learn | Кластеризация и метрики |
